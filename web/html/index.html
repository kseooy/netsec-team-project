안전한 Linux 웹서버

구성

관리자PC · 일반PC10.0.1.0/24 → 방화벽10.0.1.2 | 10.0.2.2 → 웹서버 (nginx)10.0.2.10 · 내부망 전용

보안 설정

  • 방화벽 — 웹서비스(80) 외 모든 접근 차단
